# Windows 上怎么跑检判看板

**不能双击一个 exe 直接跑。** 这是 Python 程序。Windows 上要先装 Python，再装 3 个库，填数据库密码，连上 VPN。之后双击 `启动看板.bat` 即可。

## 拷哪些文件

把整个项目文件夹拷到 Windows（外面那一层要能看到 `monitor` 文件夹）。

- **要拷：** `monitor` 里的 `.py`、`web`、`requirements.txt`、`.env.example`、`windows`
- **不要拷：** `monitor\.env`（里面有密码，到新电脑再填）
- **建议不拷：** `monitor\state`、`pending`、`backups`、`logs`（那是旧电脑的审核记录；新电脑从空白开始更干净）

## 装一次

1. 安装 [Python 3.11 或 3.12](https://www.python.org/downloads/windows/)。安装时勾选 **Add python.exe to PATH**。
2. 双击 `monitor\windows\安装依赖.bat`（窗口应是正常中文）。
3. 用记事本打开 `monitor\.env`，至少填这一行：

```
MYSQL_PASSWORD=这里填和 Mac 上同一份密码
```

其它行一般不用改：

```
MYSQL_HOST=172.16.16.101
MYSQL_PORT=33306
MYSQL_USER=root
MYSQL_DB=slzj
DASHBOARD_HOST=127.0.0.1
DASHBOARD_PORT=8765
```

## 每次怎么开

1. 先连公司 VPN（连不上内网 MySQL，扫描会报 2013）。
2. 双击 `monitor\windows\启动看板.bat`。
3. 浏览器打开 http://127.0.0.1:8765 （脚本一般会自己打开）。
4. 选「监控当天」或「审核历史日」，再点扫描。

关掉黑色窗口 = 关掉看板。

## 怎么确认成了

在看板黑色窗口里应看到类似：

```
看板 http://127.0.0.1:8765/
```

然后在页面里扫一天：能列出车次，且不再立刻报「Lost connection / 2013」，就算通了。

本机自检（可选，在项目根目录）：

```bat
.venv\Scripts\python.exe -m unittest monitor.tests.test_config monitor.tests.test_scan
```

应全部 OK。这条不连数据库。

## 和 Mac 的差别

- 看板、扫描、批准写库：一样。
- VPN 鼠标保活：Windows 已支持（停住约 30 秒会画轨迹）。不想动鼠标就改用：

```bat
.venv\Scripts\python.exe -m monitor dashboard --no-mouse
```

- Mac 那套弹出通知、launchd 开机自启：Windows 没有。要开机自启，把 `启动看板.bat` 的快捷方式放到「启动」文件夹。

## 常见问题

- **`没找到 Python`**：没勾选 PATH，或没装官方安装包。重装并勾选 PATH。
- **`未设置 MYSQL_PASSWORD`**：`monitor\.env` 不存在或密码行为空。
- **2013 / Lost connection**：VPN 没连上，或闲置被掐。先动一下鼠标再扫。
- **页面打不开**：看黑色窗口有没有报错；确认没有第二个程序占用 8765。
- **bat 窗口乱码**：这两个 `.bat` 必须是 GBK 编码。不要用记事本/VS Code 另存成 UTF-8。
