# Windows 上怎么跑检判看板

**不能双击一个 exe 直接跑。** 这是 Python 程序。Windows 上要先装 Python，再装几个库，填数据库密码，连上 VPN。之后双击 `启动看板.bat` 即可。

本分支（`binxin`）同时带着两个场景的代码，**两个看板可以同时开**：

| | 盛隆 | 镔鑫 |
|---|---|---|
| 双击 | `启动看板.bat` | `启动镔鑫看板.bat` |
| 网址 | http://127.0.0.1:8765 | http://127.0.0.1:8788 |
| 数据库 | MySQL（`MYSQL_*`） | PostgreSQL（`BINXIN_PG_*`） |
| 本机操作记录存哪 | `monitor\state` 等 | `monitor\binxin_state` |

端口、库、状态目录三者都分开，互不干扰；`.venv` 和 `monitor\.env` 两边共用一份。开两个就是开两个黑窗口，各关各的。

## 代码怎么拿到 Windows

推荐用 git，后续更新一条命令就行：

```bat
git clone -b binxin git@github.com:LAWSSSS/ScrapSteelMonitor.git
```

已经 clone 过的，每次更新：

```bat
git checkout binxin
git pull
```

**必须是 `binxin` 分支。** `main` 和 `shenglong` 上没有 `monitor\binxin`，拉下来只有盛隆看板。

密码和本机操作记录都不在 git 里（`.gitignore` 挡着），所以 `git pull` 不会覆盖你填的 `monitor\.env`，也不会动本机的操作记录。

不用 git、直接拷文件夹的话：

- **要拷：** `monitor` 里的 `.py`、`binxin`、`web`、`requirements.txt`、`.env.example`、`windows`
- **不要拷：** `monitor\.env`（里面有密码，到新电脑再填）
- **建议不拷：** `monitor\state`、`pending`、`backups`、`logs`、`binxin_state`（那是旧电脑的操作记录；新电脑从空白开始更干净，程序会自己建）

## 装一次

1. 安装 [Python 3.11 或 3.12](https://www.python.org/downloads/windows/)。安装时勾选 **Add python.exe to PATH**。
2. 双击 `monitor\windows\安装依赖.bat`（窗口应是正常中文）。
3. 用记事本打开 `monitor\.env`，把要开的那个场景的密码填上（都开就都填）：

```
MYSQL_PASSWORD=这里填盛隆库密码（和 Mac 上同一份）
BINXIN_PG_PASSWORD=这里填镔鑫库密码
```

其它行一般不用改：

```
MYSQL_HOST=172.16.16.101
MYSQL_PORT=33306
MYSQL_USER=root
MYSQL_DB=slzj
BINXIN_PG_HOST=172.31.1.102
BINXIN_PG_PORT=5432
BINXIN_PG_USER=postgres
BINXIN_PG_DB=ssqi_fcs
DASHBOARD_HOST=127.0.0.1
DASHBOARD_PORT=8765
```

## 每次怎么开

### 盛隆

1. 先连公司 VPN（连不上内网 MySQL，扫描会报 2013）。
2. 双击 `monitor\windows\启动看板.bat`。
3. 浏览器打开 http://127.0.0.1:8765 （脚本一般会自己打开）。
4. 选「监控当天」（逐车确认）、「监控当天-自动」（扫描后自动应用）或「复核历史日」。两种当天模式可随时点卡片切换。

### 镔鑫

1. 同样先连 VPN。
2. 双击 `monitor\windows\启动镔鑫看板.bat`。
3. 浏览器打开 http://127.0.0.1:8788。
4. 选业务日 → 点「扫描该日」（只核对，不应用调整）→ 逐车看方案 → 认为合适再点「确认并应用」。
   确认后会更新业务系统结果；应用前会自动保留原始记录，任何一次调整都能恢复。

关掉黑色窗口 = 关掉对应那个看板。两个窗口互不影响。

### 镔鑫结果应用错了怎么恢复

在项目根目录跑（`flow` 和日期从看板车次行下方的 `flow ...` 抄）：

```bat
.venv\Scripts\python.exe -m monitor.binxin.restore --flow <flow_code> --date <YYYY-MM-DD>
```

会把逐抓斗体积、汇总占比、扣重字段一起恢复成应用前的样子。

## 怎么确认成了

在看板黑色窗口里应看到类似：

```
看板 http://127.0.0.1:8765/
```

然后在页面里扫一天：能列出车次，且不再立刻报「Lost connection / 2013」，就算通了。

本机自检（可选，在项目根目录）：

```bat
.venv\Scripts\python.exe -m unittest monitor.tests.test_config monitor.tests.test_scan
```

应全部 OK。这条不连数据库。

## 和 Mac 的差别

- 看板、扫描、确认并应用结果：一样。
- VPN 鼠标保活：鼠标停住约 30 秒后，从你设的起点**只水平向右**移 100–1000 像素，按概率左键，再回到起点。不会乱点屏幕。
- **先设起点（必做一次）：** 把鼠标放到桌面空白处（不要放在图标、任务栏、浏览器上），双击 `monitor\windows\保存鼠标起点.bat`。2160x1440、缩放 125% 不要手算坐标，让脚本读取当前像素即可。
- 点击概率在 `monitor\.env` 里改：`MOUSE_CLICK_PROB=0.4`（0 只移动不点，1 每次都点）。
- 不想动鼠标就改用：

```bat
.venv\Scripts\python.exe -m monitor dashboard --no-mouse
```

- Mac 那套弹出通知、launchd 开机自启：Windows 没有。要开机自启，把 `启动看板.bat` 的快捷方式放到「启动」文件夹。

## 常见问题

- **`没找到 Python`**：没勾选 PATH，或没装官方安装包。重装并勾选 PATH。
- **`未设置 MYSQL_PASSWORD`**：`monitor\.env` 不存在或密码行为空。
- **`未设置 BINXIN_PG_PASSWORD`**：同上，镔鑫那一行没填。
- **2013 / Lost connection**：VPN 没连上，或闲置被掐。先设鼠标起点并让保活跑着；仍掉线可把 `MOUSE_CLICK_PROB` 调到 `0.8`。
- **页面打不开**：看黑色窗口有没有报错；确认没有第二个程序占用 8765（盛隆）或 8788（镔鑫）。
- **8788 被别的程序占了**：`启动镔鑫看板.bat --port 8789`，网址跟着改成 8789。
- **拉下来没有 `启动镔鑫看板.bat`**：分支不对。镔鑫的代码只在 `binxin` 分支上，先 `git checkout binxin`。
- **bat 窗口乱码**：这几个 `.bat` 必须是 GBK 编码。不要用记事本/VS Code 另存成 UTF-8。
